# فولدر Reference — حط فيه اللي عاجبك

سمّي الفولدر `Reference` (أو `ريفرنس`) جنب فيديوهاتك، وحط جواه أي من:
- **فيديوهات عاجباك** (ريلز لحد تاني، أو من أعمالك القديمة) — الـ skill هتتعلّم منها الإيقاع والكابشن والحركة والشكل، ومش هتنسخ لقطات.
- **صور وسكرين شوتس** (تصميم · ألوان · كادر).
- **`links.txt`** — لينكات (واحد في كل سطر).
- **`notes.md`** — كلامك: «عايز إيقاع زي ده»، «الكابشن في ده عاجبني»، «ماتحبش الحركة دي».

لو عايز تقول فيديو بعينه هو الأساس: اكتب في `notes.md` سطر «الأساسي: اسم-الملف.mp4».
