# 🎚️ فلترة الصوت بـ Auphonic — اختار الفلتر المناسب لكل فيديو

**امتى؟** الفيديو محتاج فلترة صوت: المستخدم قال «حسّن الصوت / نضّف الصوت / الصوت وحش / فيه دوشة / صدى»، أو إنت سمعت المشكلة بنفسك (مايك موبايل، شارع، كافيه، تكييف، أوضة فاضية).
مش كل فيديو يحتاجها — **الصوت النضيف ماتلمسهوش.**

## 🧭 الأول: المحلي ولا Auphonic؟ (اختار قبل أي رفع)
**المحلي هو الأساس** (مجاني · من غير رفع · من غير علامة صوتية · من غير خصم رصيد). Auphonic للحالات اللي المحلي مش بيحلها.

| حالة الصوت | الطريق |
|---|---|
| دوشة خفيفة لمتوسطة (مايك موبايل، تكييف، كافيه هادي) | **محلي** `--profile clean` |
| دوشة عالية (شارع · مروحة · زحمة) | **محلي** `--profile noisy` ← لو لسه مش مقبول → Auphonic |
| همهمة كهربا 50 هرتز | **محلي** `--profile hum` |
| **صدى** (أوضة فاضية، قاعة) | **Auphonic** (`--deverb-amount`) — المحلي مش بيشيل الصدى |
| ناس بتتكلم ورا المتحدث · صوت مكتوم/من مكالمة · مستويات متفاوتة جداً · بودكاست بمايكين | **Auphonic** (بعد موافقة المستخدم) |

```bash
python "<skill>/extras/local_enhance.py" "$W/src.mov" "$W/voice_final.wav" --profile clean
bash scripts/02b_enhance_audio.sh "$W" "$W/voice_final.wav"     # دمج الصوت في الفيديو
```
الأدوات اللي بيستخدمها: `%USERPROFILE%\.local\tools\audio-clean\deep-filter.exe` (DeepFilterNet v0.5.6 — نموذج ذكاء اصطناعي لإزالة الدوشة من الكلام، بيشتغل على المعالج، ~3 ثواني لـ17 ثانية صوت). مش موجود ← استخدم Auphonic أو `02b_enhance_audio.sh <work> --local` (أضعف) وقوله.
**اتقاس على صوت صناعي بس:** نسبة الصوت للدوشة 19 → 31 (`clean`) و48 (`noisy`) ديسيبل. مقارنته الحقيقية بـAuphonic على تسجيلات المستخدم لسه — اسمع قبل ما تسلّم، واكتب للمستخدم أي فرق تسمعه.
⚠️ ماتستخدمش `light`/ffmpeg بس لوحده للدوشة — اتجرّب وطلع أسوأ من مفيش فلترة.

**الأداة (Auphonic):** Auphonic CLI على جهاز المستخدم: `%USERPROFILE%\.local\tools\auphonic\auphonic.exe` (مش في الـPATH، شغّلها بالمسار الكامل). لو مش موجودة أو مش مسجّل دخول ← الطريق المحلي في آخر الملف.

## ⛔ قواعد قبل أي رفع (إلزامية)
1. **ده بيرفع الصوت لخدمة خارجية (Auphonic) وبيخصم من رصيد الحساب.** قبل ما ترفع قوله في جملتين وخد موافقة صريحة: مدة الصوت · الخصم المتوقع (الرصيد بالساعات، الخصم ≈ مدة الصوت) · إن الحساب المسجّل ده حساب الشغل (`auphonic user` بيوريك الإيميل). الموافقة لفيديو واحد، مش للجلسة كلها.
2. **افحص الرصيد الأول:** `auphonic.exe user` ← لو الرصيد أقل من مدة الصوت → الطريق المحلي وقوله ليه.
3. **ارفع الصوت بس، مش الفيديو** (أصغر وأخصّ): استخرجه بـffmpeg (تحت).
4. **المفتاح (API key):** ماتطلبوش في الشات وماتكتبوش في أي أمر أو ملف. مش مسجّل؟ اديله الأمر `auphonic.exe auth login` يشغّله هو بنفسه.
5. **جرّب `--dry-run` الأول** (بيطبع الإعدادات من غير ما يرفع أو يخصم) وراجع إن الفلتر هو اللي اخترته.
6. **مرة واحدة:** ماتعيدش المعالجة لتجربة إعدادات تانية من غير ما تقوله إنها هتخصم تاني.

## 🎯 اختار الفلتر حسب حالة الصوت
سمّع/حلّل الصوت (أو اسأل سؤال واحد «التسجيل كان فين وبإيه؟») واختار **صف واحد**:

| حالة الصوت | الإعدادات (تضاف على الأمر الأساسي) | ملاحظة |
|---|---|---|
| **تسجيل نضيف تقريباً** (مايك لافاليير/استوديو) — محتاج تسوية بس | `--denoise-method dynamic --denoise-amount 6` | أخف حاجة، الصوت يفضل طبيعي |
| **مايك موبايل + دوشة خفيفة** (الأشيع) | `--denoise-method dynamic` (الدرجة تلقائية) | الافتراضي الآمن لو مش متأكد |
| **دوشة عالية** (شارع · كافيه · مروحة · تكييف) | `--denoise-method dynamic --denoise-amount 18` | لو لسه عالية ارفع لـ`24` |
| **ناس بتتكلم/زحمة ورا المتحدث** | `--denoise-method speech_isolation` | بيشيل **أي حاجة غير الكلام** — ⛔ ماتستخدموش لو فيه موسيقى أو مؤثر مقصود في الفيديو |
| **صدى** (أوضة فاضية · قاعة · حمّام) | `--denoise-method dynamic --deverb-amount 0` | `0` = أقصى تقليل للصدى؛ لو الصوت اتخنق جرّب `12` |
| **همهمة كهربا / طنين ثابت** | `--denoise-method classic --dehum 50` | الكهربا في مصر 50 هرتز |
| **صوت مكتوم/رفيع أو من مكالمة/مايك ضعيف** | `--filter-method bwe` | يرجّع الترددات الناقصة (توسيع نطاق الصوت) |
| **صوت وحش جداً ومحتاج رفع جودة** (Beta) | `--filter-method studiovoice` | تجريبي — قارن بالأصل قبل التسليم |
| **صوت المتحدث بيعلى ويوطّى** (بيتحرك قدّام المايك) | زوّد التسوية: `--leveler-strength-speech 100` | الافتراضي `100` أصلاً، لو لسه متفاوت جرّب `120` |
| **فيه موسيقى خلفية مقصودة** | `--denoise-method dynamic` + `--music-gain 0` | `dynamic` بيشيل الدوشة ويسيب الكلام والموسيقى |
| **اتنين متكلمين بمايكين منفصلين** (بودكاست) | ملف لكل مايك بـ`--track id=..,file=..` | شوف `engine-egy/references/podcast.md` |

**الإعدادات الأساسية الثابتة** (في كل الحالات): `--loudness -14` (نفس علو التسليم النهائي في المحرّك)، `--max-peak -1.5`، الفلترة التلقائية شغالة (`autoeq` افتراضي).
**لو مش متأكد من الحالة:** «مايك موبايل + دوشة خفيفة» (dynamic تلقائي) أأمن من أي اختيار قوي. **بلاش** `speech_isolation` و`studiovoice` إلا لو الحالة واضحة.

## ▶️ الخطوات
```bash
A="%USERPROFILE%/.local/tools/auphonic/auphonic.exe"
W=<work>                      # فولدر الشغل (فيه src.mov)

"$A" user                                                     # 1) الرصيد والحساب
ffmpeg -v error -y -i "$W/src.mov" -vn -c:a pcm_s16le "$W/voice_in.wav"   # 2) الصوت بس

# 3) جرّب بدون رفع — راجع الإعدادات (غيّر سطر الفلتر حسب الجدول)
"$A" process "$W/voice_in.wav" --dry-run \
  --denoise-method dynamic --loudness -14 --max-peak -1.5 --output wav

# 4) بعد موافقة المستخدم: نفس الأمر من غير --dry-run ومعاه:
#    --wait --download --download-dir "$W" --output-basename voice_clean
```
### ✂️ قص علامة Auphonic الصوتية (إلزامي بعد كل تحميل)
Auphonic بيضيف **فويس/ووترمارك صوتي** في أول و/أو آخر الملف (بيحصل مع الحساب بتاعنا). **ماتدخلوش الفيديو النهائي أبداً.** بعد التحميل وقبل الدمج:
```bash
python "<skill>/extras/auphonic_trim.py" "$W/voice_in.wav" "$W/voice_clean.wav" "$W/voice_final.wav"
```
السكريبت بيقارن منحنى علو الصوت بين الأصل والمعالَج، يعرف الكلام الحقيقي بيبدأ فين، ويقص `voice_clean.wav` على **طول الأصل بالظبط**. اقرا الـJSON اللي بيطلعه:
| النتيجة | يعني إيه | تعمل إيه |
|---|---|---|
| `status: trimmed` (خروج 0) | اتقص: `head_cut` من الأول و`tail_cut` من الآخر، `confidence` ≥ 0.7 | كمّل بـ`voice_final.wav` وقول للمستخدم اتقص كام ثانية من فين |
| `no_extra` (خروج 2) | الطول متطابق — مفيش جزء زيادة | يا إما مفيش علامة، يا إما **مدموجة فوق الكلام** (مش بتتقص). اسمع ٥ ثواني بالأول والآخر؛ لو سمعتها ← ماتسلّمش الصوت ده |
| `low_confidence` (خروج 3) | العلامة في النص أو متداخلة، ومش قادر أحددها | **ماتقصّش بإيدك بالتخمين.** خلّي المستخدم يسمع، أو ارجع للطريق المحلي |
⚠️ مش بيقدر يشيل علامة **مدموجة فوق الكلام نفسه** (مفيش حاجة تتقص) — الحل الوحيد ساعتها الطريق المحلي (تحت) أو إن المستخدم يتواصل مع Auphonic.
**تحقق بعد القص:** `ffprobe` على `voice_final.wav` لازم يطلع نفس مدة `voice_in.wav` (±0.05 ث). وقبل التسليم، في وضع «مراجعة كاملة» اسمع/افحص أول وآخر ثانيتين للتأكد إن العلامة راحت.

بعد ما ينزل `voice_clean.wav` وتقصّه (افحص الاسم بـ`ls "$W"` لو اتغيّر) — **ادمج `voice_final.wav` مش `voice_clean.wav`**:
- `bash scripts/02b_enhance_audio.sh "$W" "$W/voice_final.wav"` (بيدمجه في `src.mov` ويحفظ الأصل `src_rawaudio.mov`).
اعمل ده **قبل التفريغ** عشان وِسبر يسمع صوت نضيف.

## ✅ بعد المعالجة
- قارن الأصل بالمعالَج بنفسك أو خلّي المستخدم يسمع ٥-١٠ ثواني (في وضع التوفير: هو اللي يسمع). لو الصوت بقى «تحت الماية/روبوتي» ← خفّف (`--denoise-amount` أقل، أو `dynamic` بدل `speech_isolation`) وقوله إن إعادة المعالجة هتخصم تاني.
- قول للمستخدم في جملة: **الفلتر اللي اخترته ولماذا + الرصيد اللي اتخصم** (`auphonic.exe user` تاني).
- ماتبعتش ملف المستخدم لـAuphonic لو هو قال «ماتطلعش حاجة برا».

## 🔁 الطريق المحلي (من غير Auphonic)
الأوتوماتيك: لو مفيش رصيد، أو المستخدم رفض الرفع، أو الصوت نضيف تقريباً، أو Auphonic مش مسطّبة:
`bash scripts/02b_enhance_audio.sh <work> --local` (ffmpeg: شيل دوشة + قص الواطي + ضغط + معايرة) — أضعف من Auphonic على الصدى والدوشة العالية، قوله ده.
