# تعلّم ستايل من فيديو مرجعي (Style DNA)

فكرتها مأخوذة من Reel Studio وأعدت صياغتها: الفيديو المرجعي بيورّيك **النتيجة النهائية** بس — مش المشروع ولا الإعدادات. فإنت بتستنتج **قرارات** وتنقلها لفيديو المستخدم، مش بتنسخ لقطات. الفيديو المرجعي ممكن مايكونش مرخّص للاستخدام كلقطات.

## 1) حدّد الفيديوهات المرجعية
سجّل بالاسم كل فيديو ودوره (ستايل · دليل · لقطات مصدر). حلّل بس اللي المستخدم سمّاه أو اللي في فولدر `Reference`. ماتفتحش ميديا تانية.

## 2) افحص (بأدوات موجودة عندك: ffprobe وffmpeg)
```bash
ffprobe -v error -show_entries format=duration:stream=width,height,r_frame_rate,codec_type -of json ref.mp4
ffmpeg -v error -i ref.mp4 -vf "select='gt(scene,0.25)',showinfo" -f null - 2>&1 | grep pts_time     # مرشّحين للقطعات
ffmpeg -v error -i ref.mp4 -vf "fps=1/2,scale=360:-1,tile=4x4" -frames:v 1 sheet.jpg                    # ورقة لقطات
ffmpeg -v error -ss 2.8 -t 0.6 -i ref.mp4 -vf fps=12 frames/%03d.png                                    # لحظة انتقال بالإطار
```
(أو `07_contact_sheet.sh` في المحرّكين.) افحص: البداية · نص الفيديو · نقاط الانتقال المهمة · النهاية.
- **الحركة تتفحص إطار بإطار** — الورقة بتحدد اللحظة بس، مش بتثبت easing ولا تسلسل.
- **مابتسمعش الفيديو**: اسأل المستخدم الصوت بيعمل إيه في اللحظات المهمة، أو اكتبها «غير معروفة».
- كاشف القطعات بيقترح قطعات بس — اتأكد من الإطارات حواليه: قطع ولا زوم ولا قناع ولا انتقال؟

## 3) كل ملاحظة بدليل
اكتب في `style-analysis/<ref>.md` صف لكل ملاحظة:

| الحقل | يحتوي |
|---|---|
| `id` | رقم ثابت |
| `timecodes` | المدى بالظبط في المرجع، مثلاً `00:03.20–00:05.60` |
| `claim` | اللي بيحصل فعلاً (وصف الفعل مش اسم التأثير) |
| `basis` | `observed` (شفته) · `measured` (قيس بأداة) · `inferred` (استنتاج نيّة) |
| `confidence` | high / medium / low + السبب |
| `trait` | `invariant` (يتكرر) · `adaptive` (يتغير حسب المحتوى) · `uncertain` |
| `exceptions` | حالات مخالفة أو تغطية ناقصة |

مثال: «نفس الكارت الورقي بيهبط على اللوحة عند 00:03.20 ويفضل ظاهر وقت ظهور العنوان» = observed. «صاحب الفيديو قصد يوحي بالثقة» = inferred. إطارين مش بيثبتوا إعدادات spring. شكل الموجة الهادي مش بيقيس الأهمية. مرجع واحد = اتجاه **مبدئي**؛ ماتسمّيش قاعدة `invariant` إلا لو اتكررت في أمثلة فعلية. اسم القناة وشهرة صاحبها مش دليل. الغير معروف يتكتب «غير معروف» مش تقدير صامت.

## 4) ابني `style-dna.md`
أقسام ثابتة: **الهوية والنطاق** · **المراجع** (أسماء + أي حدود وصول) · **ثوابت ملاحظة** (بدليل وثقة) · **متغيرات تتكيّف** (كثافة · تخطيط · توقيت · بُعد الحركة) · **سمات غير مؤكدة** (ماتتحولش قاعدة بصمت) · **منطق التطبيق** (إزاي القواعد تخدم الفيديو ده) · **ممنوعات** (تغييرات بتمسح الأسلوب) · **حدود** (اللي الدليل مايثبتوش).
الحالة `draft` لحد ما المستخدم يراجع. احفظ نسخة قبل ما تبدّل DNA اتراجع.

## 5) طبّقه على الفيديو الفعلي
لكل لحظة مهمة اكتب صف في خطة المشاهد: اللحظة ← قرار الأسلوب المطبّق ← ليه يناسب الكلام ده. **عدّل على الكلام الجديد مش على لقطات المرجع.** ورّي المستخدم مقطع قصير (6-10 ثواني) من أصعب مكان قبل ما تكمّل الفيديو كله. لو المرجع بيطلب حاجة المحرّك مش بيعملها، قول كده بصراحة واقترح أقرب بديل.

## 6) قاعدة التنازل
الريفرنس يكسب على الاقتراحات الجاهزة، لكن **البراندينج يكسب على الريفرنس** في اللون والخط واللوجو.
