# وضع المونتاج — مقاطع من غير كلام

فولدر فيه مقاطع كتير (كافيه · أكل · منتج · مكان · إيفنت) والمطلوب فيديو واحد بإيقاع.
⛔ **من غير تفريغ ولا كابشن ولا مشاهد مرسومة.** الاختيار كله على المشهد نفسه.
محتاج منه حاجة واحدة: **فولدر المقاطع**. ماتسألوش عن ألوان ولا لوجو ولا حساب — مفيش نص أصلاً.

**المحرّك بيختار إزاي:** كل لحظة في كل مقطع بتتقاس بأربعة — وضوح الصورة · حركة بمقدار · إضاءة · لون.
الوضوح **نسبي** (بيقارن مقاطعك ببعض)، والحركة والإضاءة **مطلقين**.
والمتجمّد والضلمة والمهزوز درجاتهم **بتتضرب** مش بتتطرح: يعني مش هينفعهم إن باقي صفاتهم حلوة.
وأول تلت ثانية وآخر تلت ثانية من كل مقطع بيتقصوا — لحظة الإيد على الموبايل.

### 1) الفحص
```bash
python3 scripts/12_montage.py <work> scan <فولدر_المقاطع> --shot 1.5
```
بيفحص 4 مقاطع في نفس الوقت. القياس: **30 ثانية فيديو ≈ 15 ثانية فحص** — يعني 30 مقطع
كل واحد 10 ثواني ≈ دقيقتين ونص. شغّله في الخلفية وقوله يتوقع قد إيه.
بيطبع كل مقطع بدرجته وأحلى لحظة فيه، وبيكتب `montage.json`.

### 2) وريه اللقطات — ورقة واحدة مترقّمة
```bash
python3 scripts/12_montage.py <work> sheet          # 4 عواميد · ارتفاع اللقطة 180
```
كل لقطة عليها رقم مقطعها. **اقرا الورقة لوحدها — ماتقراش الصور واحدة واحدة.**
واعرضها عليه: «دي أحلى لحظة في كل مقطع — عايز أشيل إيه؟»

### 3) شيل اللي مش عاجبه
```bash
python3 scripts/12_montage.py <work> drop 4 11      # بيشيل
python3 scripts/12_montage.py <work> keep 1 2 5 9   # بيسيب دول بس
python3 scripts/12_montage.py <work> undo           # تراجع
```

### 4) الترتيب والإيقاع
```bash
python3 scripts/12_montage.py <work> plan --dur 30 --shot 1.5
```
| | |
|---|---|
| `--order energy` (الافتراضي) | بيبدّل متحرك/هادي وأقوى لقطة في الأول |
| `--order best` \| `folder` | بالدرجة · بترتيب الفولدر |
| `--bpm 96` | أطوال اللقطات على البيت — القطع بيقع مع الصوت |
| `--dur 0` | كل المقاطع من غير سقف |

أطوال اللقطات بتتغيّر بنمط متكرر (1.0 · 0.82 · 1.24 · 0.94 من `--shot`) عشان مايبقاش ممل.

### 5) التركيب
```bash
python3 scripts/12_montage.py <work> build <work>/montage.mp4
```
| | |
|---|---|
| `--ar 9:16` | المقاس: `9:16` · `4:5` · `1:1` · `16:9` (القص من النص) |
| `--xfade 0.25` | تلاشي بين اللقطات بدل القطع الحاد |
| `--zoom 0` | بيقفل الزوم الداخلي الخفيف |
| `--amb 0.3` | بيسيب صوت المكان واطي (بشرط كل المقاطع فيها صوت ومن غير تلاشي) |

**الزوم بيشتغل بس لو المصدر أكبر من المخرَج بمرة ونص على الأقل** (4K مثلاً)، وإلا المحرّك بيقفله
لوحده ويقولك — لأن القص على مصدر بحجم المخرَج بيطلّع الزوم متقطّع.

### 6) الصوت والتسليم — نفس خط الكلام
```bash
bash scripts/06b_master.sh <work> <work>/montage.mp4 <work>/montage-master.mp4
```
حط ملفه الصوتي `<work>/bg-audio.mp3` في فولدر الشغل قبلها. المونتاج بيطلع بمسار صامت لو ماطلبتش
صوت المكان، فالخلفية الصوتية هنا مش زينة — من غيرها الفيديو ساكت.

### ⛔ قواعد الوضع
1. **ماتفرّغش ولا تعمل كابشن.** لو في المقاطع كلام مهم يبقى ده وضع الكلام مش المونتاج.
2. **وريه الورقة قبل التركيب** — هو اللي يشيل اللي مش عاجبه، مش إنت.
3. **مفيش ثيم ولا ألوان ولا تدرّج** — الصورة بتطلع بألوانها الأصلية (نفس القاعدة 4).
4. المدة المعقولة **20-40 ثانية**؛ أكتر من كده المشاهد يزهق.
5. **لا نشر ولا جدولة** — التسليم ملف بس.
